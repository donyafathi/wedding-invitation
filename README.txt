# Digital Wedding Invitation

## Files
- `index.html` — complete responsive invitation
- `assets/wedding-card.jpg` — the supplied wedding-card image
- `assets/music.mp3` — add your wedding music here

## Customize the venue
Open `index.html` and replace:
- `[نام تالار / محل برگزاری]`
- `[آدرس کامل محل برگزاری]`
- `[تاریخ و ساعت مراسم]`
- the Google Maps `query=` value

## Customize the music
Put your audio file at:
`assets/music.mp3`

The music intentionally starts only after the wax seal is clicked, so it complies with normal browser autoplay restrictions.

## Run locally
You can open `index.html` directly in many browsers. For the most reliable result, serve the folder with a simple local web server.

## Publish on GitHub Pages
Upload `index.html` and the `assets` folder to a GitHub repository, then enable GitHub Pages for the repository's main branch.
